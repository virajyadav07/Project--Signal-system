# Project--Signal-system
 This project is an ECG Signal Filtering and Analysis system developed using Python.  It processes ECG (Electrocardiogram) signals and removes unwanted noise using digital signal processing techniques. The project helps improve the quality of ECG signals and makes important features such as R-peaks easier to identify and analyze.
Features

1. ECG Signal Loading
2. Raw ECG Signal Visualization
3. Noise Reduction
4. Baseline Wander Removal
5. 50 Hz Power-Line Noise Removal
6. ECG Signal Filtering
7. R-Peak Detection
8. Heart Rate Calculation
9. Comparison of Raw and Filtered ECG Signals
10. Graphical Signal Analysis

How It Works

1. User provides or loads an ECG signal dataset.
2. The program displays the original ECG signal.
3. Noise present in the ECG signal is identified.
4. Digital filters are applied to remove unwanted noise.
5. The filtered ECG signal is displayed.
6. R-peaks are detected from the filtered signal.
7. Heart rate is calculated using the detected R-peaks.
8. The results are displayed using graphs and calculated values.
